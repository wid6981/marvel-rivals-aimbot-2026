## FAQ

**Which heroes does the aimbot work best with?**  
Hitscan heroes (Hawkeye, Punisher, Hela) benefit most. Projectile heroes need the prediction setting enabled.

**Is there an anti-cheat in Marvel Rivals?**  
Marvel Rivals uses Ricochet anti-cheat. External tools with no kernel driver have not been detected as of current patch.
